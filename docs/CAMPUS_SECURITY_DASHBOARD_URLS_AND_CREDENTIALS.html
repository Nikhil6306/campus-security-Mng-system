Login Request Body Example

{
  "email": "admin@dsvv.edu.in",
  "password": "Admin@123",
  "expectedRole": "admin"
}

The expectedRole field enforces portal-specific login — if the user's actual database role does not match, login is rejected with: "You are not authorized to access this login portal."

8. Password Reset Instructions

Via Forgot Password (OTP Flow)

  1. Go to /forgot-password
  2. Enter your registered email address
  3. Receive a 6-digit OTP via email (requires Resend API to be configured)
  4. Enter the OTP — valid 10 minutes, max 5 attempts, 60-second resend cooldown
  5. Enter and confirm your new password
  6. Sign in with the new password at your role's login page
OTP Email Configuration Required: Add these to .env.local before OTP emails will be delivered: 
RESEND_API_KEY=re_your_key_here
RESEND_FROM_EMAIL=security@dsvv.ac.in
RESEND_ENABLE_DEVELOPMENT_DELIVERY=true
Without these settings, OTP emails are silently dropped. Get your Resend API key at resend.com.
